# DriveSaathi | Home Driving & Riding Trainer Marketplace

> **Your vehicle. Your trainer. Your confidence.**

DriveSaathi is a premium, trusted doorstep marketplace that allows customers to book verified male or female driving and riding mentors who travel to the customer's home or a safe practice ground.

---

## 🚀 Key Features

* **3-Minute Frictionless Booking:** Select vehicle brand, model, transmission, experience level, practice goals, and doorstep address.
* **Gender-Aware Mentorship:** Respectful options for *Female Mentor*, *Male Mentor*, or *No Preference*.
* **Vector GPS Radar & Matching Engine:** Multi-factor scoring (Vehicle compatibility, distance, availability, skills, ratings).
* **Live Day-of-Session Tracking:** Live stopwatch timer, GPS radar tracking, and 1-tap **Emergency SOS** (112 Police hotline + 24×7 Safety Desk).
* **AI Training Assistant & Coach:** Automatically evaluates mentor observations to generate student confidence scorecards and personalized 60-min practice drills.
* **Multi-Role Portals:**
  * 📱 **Learner / Client Portal:** Booking, live session tracking, AI coach report, DrivePoints wallet, and chat.
  * 👨‍🏫 **Trainer Partner Portal:** Incoming booking alerts with countdown, earnings hub (₹58,400/mo), weekly bank payouts, and availability calendar.
  * 🔒 **Super Admin Control Center:** Real-time KPI dashboard, active sessions radar map, KYC document audit desk, pricing matrix configurator, and safety escalation desk.
* **Unified Authentication:** Phone OTP, Google 1-Tap OAuth, and Passwordless Magic Link Email.
* **24×7 Customer Help Desk:** Integrated Live Chat Support, Toll-Free Hotline (1800-200-8899), and Ticket Management.

## 🛠️ Tech Stack

* **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
* **State Management:** Reactive Store with LocalStorage synchronization
* **Sound Effects:** Web Audio API sound synthesizer
* **Testing:** Vitest (13/13 unit tests passing)
* **Build Tool:** Vite
